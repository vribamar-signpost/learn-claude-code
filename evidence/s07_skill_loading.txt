### Improvements

#### 1. **Navigation clarity for newcomers** (Structure)
- The README excels at explaining *why* agent harnesses matter, but buried guidance on *where to start* for three audience types:
  - **Total beginners**: Read s01-s05 sequentially (foundations)
  - **Experienced engineers**: Jump to s10+ (advanced patterns)
  - **Implementation-first learners**: Run `code.py` in s01 before reading philosophy
  
**Suggestion**: Add a "Choose Your Path" callout after the quick start showing these three entry points with expected time investment.

#### 2. **Table clarity: Legacy vs. Current mapping** (Information Architecture)
The legacy-to-current mapping table is accurate but dense. The mermaid diagram in "Learning Path" is excellent; consider **adding a second diagram** showing the 12→17 lesson bridge explicitly, with visual grouping of:
  - Direct translations (s01→s01, s02→s02)
  - Moved lessons (old s03→new s05)
  - New mechanisms (s03, s04, s09, s12, s14)

This 90-second visual prevents readers from accidentally mixing chapter numbering across tracks.

#### 3. **Quick Start: Environment setup explicitness** (Operations)
```sh
cp .env.example .env   # configure ANTHROPIC_API_KEY
```
This assumes `.env.example` exists. Add one more line:
```sh
# Edit .env and set:
# ANTHROPIC_API_KEY=sk-ant-...
```
Explicit key guidance prevents silent failures.

#### 4. **s15 placement clarity** (Pedagogy)
The README states: *"s15 reconnects the cumulative runtime; s16 and s17 then study workflow orchestration and goal closure."*

This is correct but the mermaid diagram makes it look like s7 leads directly to s7 (orchestration phase). Clarify the transition:

**Suggestion**: Expand the transition text between Phase2 and Phase3:
> "s15 brings all mechanisms together in one integrated loop. s16 and s17 extend this loop for specialized use cases: s16 for saved workflows with resumable journals, s17 for goal-controlled continuation."

#### 5. **Deep link accessibility** (UX)
GitHub rendering shows links like `[s01](./s01_agent_loop/)` but web users need anchor-to-anchor linking. The web app comment is noted but consider:
- Adding a "URL shortcuts" section for each major phase
- Recommending `#table-of-contents` style anchors in web deployment

Minor — only affects off-GitHub reading.
