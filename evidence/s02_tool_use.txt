This project is **Learn Claude Code** -- a comprehensive 17-lesson tutorial on building agent harnesses for large language models (LLMs). Here's what it's about:

## Core Philosophy

The project teaches that **agency (the ability to perceive, reason, and act) comes from the model itself through training, not from orchestration code**. The role of engineers is to build the "harness" -- the infrastructure that gives an intelligent model a place to operate effectively.

## Key Concepts

The project breaks down agent harness engineering into 17 progressive lessons, each adding one mechanism:

1. **Core capabilities** (s01-s04): Agent loop, tool use, permissions, hooks
2. **Complex work handling** (s05-s08): Planning, subagents, context compaction
3. **Memory & long-running tasks** (s09-s12): Memory systems, task persistence, background jobs, scheduling
4. **Collaboration & integration** (s13-s15): Multi-agent teams, MCP plugins, integrated harness
5. **Orchestration & goal closure** (s16-s17): Workflow runtime, goal-controlled loops

## The Central Loop

All agents follow the same pattern:
```
User → messages[] → LLM → response → contains tool_use? → execute tools → append results → loop back
```

The model decides when to use tools; the harness just executes what the model asks.

## What It Teaches

- How to give agents **tools** (file I/O, shell, APIs, etc.)
- How to provide **knowledge** (docs, references, style guides)
- How to manage **context** compaction for long conversations
- How to enable **teams** of agents working together
- How to **extend** agents via external tools (MCP)
- How to orchestrate **workflows** and **goals**

The project emphasizes that smart agent products aren't built by stacking prompt chains and if-else rules, but by designing effective environments where trained models can demonstrate their reasoning and acting capabilities.
