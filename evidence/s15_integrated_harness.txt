**README Summary:**

This is a **harness engineering course** teaching how to build operational environments for AI agents—not how to make agents intelligent (that comes from model training). The core insight: **Agency comes from the model. The harness is the vehicle.**

**Key Takeaways:**
- **17 progressive lessons** (s01–s17) from basic agent loop to goal-controlled continuation
- **Core pattern**: messages → LLM → tool_use blocks → execute → loop
- **Not about**: prompt chaining, node graphs, or Rube Goldberg automation
- **What it teaches**: tools, knowledge curation, context management, permissions, tasks, teams, workflows, goal closure

**The Harness includes:**
- Agent loop (messages, tool dispatch)
- 17+ mechanisms (permissions, hooks, planning, subagents, skill loading, context compaction, memory, task system, background work, scheduling, teams, MCP integration)
- Course progression: simple → complex → collaborative → orchestrated

**Two paths after:**
1. **Kode Agent CLI** — open-source coding agent
2. **Kode Agent SDK** — embed agent capabilities in apps

The repository teaches that you aren't engineering intelligence; you're building the world intelligence inhabits. Build it well, the model does the rest.
