**Core Agent Loop Pattern** (from `s01_agent_loop/README.md` and `code.py`):

### The Minimal Loop (30 lines)
```python
def agent_loop(messages):
    while True:
        response = client.messages.create(
            model=MODEL, system=SYSTEM, messages=messages,
            tools=TOOLS, max_tokens=8000,
        )
        messages.append({"role": "assistant", "content": response.content})

        tool_calls = [
            block for block in response.content if block.type == "tool_use"
        ]
        if not tool_calls:
            return

        results = []
        for block in tool_calls:
            output = run_bash(block.input["command"])
            results.append({
                "type": "tool_result",
                "tool_use_id": block.id,
                "content": output,
            })
        messages.append({"role": "user", "content": results})
```

### Key Principles
1. **Continue signal**: Model calls a tool (`tool_use` block present) → Execute & loop
2. **Stop signal**: No `tool_use` block → Exit loop
3. **Message flow**: User query → LLM → [Tool execution → Results back → LLM]* → Final response
4. **One loop unchanged**: All 17 lessons (S01-S17) build on this same core loop

### Foundation
- **Tool execution**: Direct inspection of `response.content` blocks
- **Result feeding**: Tool results appended as `{"role": "user", "content": results}`
- **Safety**: Dangerous commands blocked (rm -rf, sudo, shutdown, etc.)
- **Timeout**: 120s per command execution

The subsequent lessons (S02-S17) layer on: tool use patterns, permissions, hooks, skill loading, context compaction, memory, task systems, background execution, team coordination, MCP integration, and goal-driven loops.
