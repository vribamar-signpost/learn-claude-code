This is a comprehensive tutorial repository on **harness engineering for AI agents**, specifically focused on building the operational infrastructure around Claude (and similar LLMs) so they can act as agents in complex environments.

The key points from the README:

1. **Core Philosophy**: Agency comes from model training, not from code orchestration. The harness is the "vehicle" that lets the trained model (the "driver") operate effectively.

2. **What a Harness Is**: Tools + Knowledge + Observation + Action Interfaces + Permissions that enable an agent to work in a specific domain.

3. **17 Progressive Lessons**: The course builds from basics (s01: Agent Loop) through advanced topics (s17: Goal Loop), teaching:
   - Agent loops and tool use
   - Permissions and hooks
   - Planning and subagents
   - Context management
   - Tasks and background operations
   - Agent teams and coordination
   - Integration with external tools (MCP)
   - Workflow orchestration
   - Goal-directed continuation

4. **The Agent Pattern**: A simple loop where the LLM receives messages, decides whether to call tools, and the harness executes those tool calls and feeds results back.

5. **Quick Start**: Run lessons with commands like `python s01_agent_loop/code.py`

The repository emphasizes building practical, composable harness mechanisms around a core agent loop, with each lesson isolated to teach one specific pattern.
